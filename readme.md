# Super EEvEE Dex (WIP)

A simple pokedex and team building software with a WebUI

## Instructions for Build and Use

[Software Demo (COMMING SOON)](Put_Your_Video_Link_Here)

Steps to build and/or run the software:

1. Clone Git Repo
2. Move the data from `appsettings.json.template` to `appsettings.json` and update if needed.
3. Run `dotnet run` to start the web UI.

Instructions for using the software:

1. Software is a WIP, currently just has a very basic type system.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Dotnet 10.0
* Asp.Net with razor pages and authentication.
